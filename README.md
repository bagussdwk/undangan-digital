# Undangan Digital — Mega Ayu Lestari & Bagus Dwi Kurniawan

Tema: Elegant Sage Green & Gold  
Tanggal: Rabu, 6 Januari 2027

## Menjalankan
Buka `index.html` atau aktifkan GitHub Pages dari Settings → Pages dengan source branch `main`, folder `/ (root)`.

## Personalisasi sebelum dibagikan
Edit objek `WEDDING` di `script.js`:
- Nama orang tua
- Jam akad dan resepsi
- Nama/alamat lokasi dan URL Google Maps
- Nomor WhatsApp tujuan RSVP
- Nama bank, nomor rekening, dan nama pemilik rekening

Tambahkan musik milik Anda di `assets/audio/music.mp3` (buat folder `assets/audio`). Musik baru berjalan setelah tamu menekan tombol Musik.

## Foto
Ganti URL foto contoh dari Unsplash di `style.css` dengan foto pasangan.

## Nama tamu personal
Gunakan parameter URL, misalnya:
`https://username.github.io/undangan-digital/?to=Nama%20Tamu`

## Catatan
RSVP diarahkan ke WhatsApp, bukan disimpan ke database. Nomor WhatsApp, rekening, nama orang tua, lokasi, dan foto masih berupa data contoh yang harus diganti sebelum undangan dibagikan.
