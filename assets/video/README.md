# Video background undangan

Letakkan file video MP4 di folder ini. Nama file harus sama persis:

- home.mp4 — background bagian Home
- mempelai.mp4 — background bagian Mempelai
- acara.mp4 — background bagian Acara
- cerita.mp4 — background bagian Cerita / Love Story
- galeri.mp4 — background bagian Galeri
- hadiah.mp4 — background bagian Hadiah / Amplop Digital
- rsvp.mp4 — background bagian RSVP
- penutup.mp4 — background bagian penutup / footer

Video diputar otomatis, tanpa suara, dan berulang. Gunakan video MP4 landscape (disarankan 1920×1080 atau 1280×720), ukuran file sekecil mungkin agar undangan tetap cepat dibuka di HP.

Saat file MP4 belum tersedia, halaman tetap menampilkan gambar poster sementara. Untuk mengganti video, cukup unggah MP4 dengan nama di atas ke folder ini; tidak perlu mengubah HTML atau JavaScript.
